TANDOORI RESTAURANT + SUPABASE

1. Open SUPABASE_SETUP.sql in Supabase SQL Editor and run it.
2. The website is already configured with your Supabase project URL and publishable key.
3. Open index.html in a local web server (for example VS Code Live Server).
4. Go to Order Now and submit a test order.
5. In Supabase: Table Editor -> orders. The submitted order should appear there.

IMPORTANT:
- The publishable key is intended for frontend use. Keep your Supabase service-role/secret key out of this website.
- If you already created an orders table with different column names, use the included SQL to align the table or tell us the exact columns before changing the JavaScript.
